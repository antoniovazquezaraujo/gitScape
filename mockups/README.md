# Mockups — «plano doble» (PRs + ficheros)

Maqueta conceptual para decidir cómo enseñar las PRs junto al árbol de ficheros de gitScape (datos ficticios de **LeTrain**; sin build ni dependencias).

**Abrir:** doble clic en `two-planes.html`.

**Qué mirar:**
- **V1 · profundidad (Z)** — ¿el «wow» compensa la oclusión entre planos y el coste L?
- **V2 · apilado (Y)** — ¿bastan dos bandas y cables verticales? ¿Se leen las dos capas a la vez?
- **V3 · híbrido (un plano)** — ¿las tarjetas ancladas junto a los ficheros ayudan o estorban?

Clic en una PR resalta sus ficheros y dibuja las conexiones; clic en un fichero busca una PR que lo toca.
